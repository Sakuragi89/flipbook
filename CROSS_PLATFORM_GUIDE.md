# Cross-Platform Usage Guide
**Works on Windows PC, Android Mobile, and More!** 📱💻

---

## 🖥️ **WINDOWS PC FEATURES**

### Image Selection:
✅ **Shift + Click** on thumbnails - Select multiple images  
✅ **Ctrl + Click** on thumbnails - Add/remove from selection  
✅ **Select All** button - Select everything instantly  
✅ **Deselect All** button - Clear all selections  

### Gallery Controls:
✅ **Click** any image to open gallery  
✅ **Arrow Keys** (← →) - Navigate between images  
✅ **Mouse Wheel** - Zoom in/out  
✅ **Click + Drag** - Pan when zoomed  
✅ **+/- Keys** - Zoom controls  
✅ **0 Key** - Reset zoom  
✅ **Escape** - Close gallery  

### Downloads:
✅ **Download button** in gallery - Single image  
✅ **Download Selected** - All selected images  
✅ **Download All** - Entire collection  
✅ **Fast bulk downloads** - 500ms delay between files  

---

## 📱 **ANDROID MOBILE FEATURES**

### Image Selection:
✅ **Long-press (hold)** thumbnails - Select/deselect  
✅ **Vibration feedback** when selected (if supported)  
✅ **Select All** button - Works perfectly  
✅ **Deselect All** button - Clear selections  

### Gallery Controls:
✅ **Tap** any image to open gallery  
✅ **Swipe left/right** - Navigate between images  
✅ **Pinch to zoom** - Two-finger zoom in/out  
✅ **Drag when zoomed** - Pan around image  
✅ **Tap X button** - Close gallery  

### Downloads:
✅ **Download button** in gallery - Single image (BEST METHOD)  
⚠️ **Download Selected** - Works but may have browser limits  
⚠️ **Download All** - May prompt for permission  
✅ **Slower downloads** - 1000ms delay for stability  

### Mobile Limitations:
⚠️ **Bulk downloads** may be limited by browser (5-10 at once)  
⚠️ **Browser may ask permission** for multiple downloads  
💡 **Best practice**: Download one-by-one from gallery  

---

## 🎯 **RECOMMENDED WORKFLOWS**

### Windows PC - Bulk Download Workflow:
```
1. Browse flipbook
2. Shift+Click favorite images
3. Click "Download Selected (X)"
4. Wait for downloads to complete
5. Check Downloads folder
```

### Android Mobile - Gallery Download Workflow:
```
1. Browse flipbook
2. Tap image to open gallery
3. Tap "Download" button
4. Swipe to next image
5. Tap "Download" again
6. Repeat for each desired image
```

### Android Mobile - Bulk Download (Small Sets):
```
1. Long-press thumbnails to select (max 5-10)
2. Tap "Download Selected"
3. Approve downloads if prompted
4. Images save to Downloads folder
```

## 🔧 **TROUBLESHOOTING**

### PC Issues:

**Selection not working?**
- Make sure you're holding Shift or Ctrl while clicking
- Check if thumbnails show green border when selected

**Downloads blocked?**
- Check browser popup settings
- Allow downloads from your GitHub Pages domain

**Keyboard shortcuts not working?**
- Click anywhere on page first to focus
- Gallery must be open for zoom shortcuts

### Mobile Issues:

**Long-press not selecting?**
- Hold for full 500ms (half second)
- Don't move finger while holding
- Look for vibration feedback

**Downloads not working?**
- Check browser permissions
- Try downloading from gallery instead
- Some browsers limit bulk downloads

**Can't select many images?**
- This is normal on mobile
- Download from gallery one-by-one
- Or use Select All (but download may be limited)

## ⌨️ **COMPLETE KEYBOARD SHORTCUTS (PC)**

**Main View:**
- `Arrow Left/Right` - Previous/Next image
- `Enter` or `Space` - Open gallery
- `Shift + Click` - Select image
- `Ctrl + Click` - Toggle selection

**Gallery View:**
- `Arrow Left/Right` - Navigate
- `+` or `=` - Zoom in
- `-` - Zoom out
- `0` - Reset zoom
- `Escape` - Close gallery

- `Tap image` - Open gallery
- `Swipe left/right` - Navigate
- `Pinch open` - Zoom in
